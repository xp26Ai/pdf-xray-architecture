# pdf-xray-architecture

[English](README.en.md)

**ملف PDF ممسوح ← حقول مستخرجة، لكل حقل مصدره ودرجة ثقته — بلا إنترنت.**

> **هذا النظام يعمل في بيئة إنتاج لدى جهة عملي، والكود ملكها. هذا المستودع يوثّق المعمارية والقرارات الهندسية وطريقة البناء.**

نظام استخراج حتمي للمستندات الممسوحة في 16,543 سطر JavaScript.
خادم واحد فيه 34 نقطة نهاية، و41 وحدة في `lib/`، و16 حزمة فحص دخان.
التعرف الضوئي (OCR) عربي/إنجليزي يعمل محلياً بالكامل عبر Tesseract WASM.
طبقة الذكاء الاصطناعي إثراء اختياري فوق النتيجة، وليست شرطاً لها.

---

## المشكلة

الفواتير وأوامر الشراء وسندات التسليم تصل ممسوحة بجودات متفاوتة. والمطلوب أرقامها بدقة.

إرسال كل ملف إلى نموذج سحابي له 3 عيوب. النتيجة غير قابلة للتكرار.
والبيانات تغادر الخادم. والخدمة تتوقف مع انقطاع الإنترنت أو نفاد الحصة.

والمطابقة النصية الحرفية وحدها هشة: ضجيج المسح يغيّر الحروف نفسها بين نسخة وأخرى.

المطلوب: مسار حتمي يعطي النتيجة نفسها في كل مرة، مع درجة ثقة صادقة لكل حقل.

## كيف يشتغل

| الطبقة | الوظيفة |
|---|---|
| بصمة المستند | تحديد هوية المُصدر من صياغة الترويسة، بمقاومة لأخطاء OCR الشائعة |
| OCR محلي | Tesseract WASM بعمليتين ابنتين معزولتين (عربي وإنجليزي)، وبيانات اللغة 24.9 MB داخل المشروع |
| التصنيف | 5 أنواع مستندات بكلمات مفتاحية موزونة بالعربية والإنجليزية، بلا أي اتصال خارجي |
| القوالب المدرّبة | مراسي «تسمية ← قيمة» تُدرَّب من واجهة ويب، وتُطبَّق حتمياً على كل مستند مطابق |
| الثقة والمصدر | لكل حقل ثقتان منفصلتان `{found, value}` مع مصدر الاستخراج وتصنيف الموثوقية |
| إثراء AI اختياري | ميزانية يومية 450 نداء لكل نموذج، وطابور 14 نداء بالدقيقة، وكاش SHA-256 على القرص |

المسار من الملف إلى الحقول:

```
PDF ──> بصمة المستند ──> قالب مدرّب ──> استخراج حتمي (مراسي + أنماط)
            │                                   │
            ▼                                   ▼
      OCR محلي معزول                حقول: قيمة + {found, value} + مصدر
                                                │
                                    (اختياري) نموذج سحابي للإثراء
                                                │
                            تقاطع النتيجتين ──> reproducible / verified / ai_only
```

قواعد الثقة حتمية ومكتوبة في وحدة واحدة نقية بلا أي إدخال/إخراج:

- `found`: قوة تحديد الحقل. مرساة مطابقة تماماً 0.95، ومطابقة تقريبية 0.75، ونمط نصي 0.70.
- `value`: صحة القيمة. تبدأ من ثقة OCR، وتُرفَع إلى 0.85 عند مطابقة الصيغة المتوقعة.
- اتفاق المسار الحتمي مع النموذج السحابي يرفع `value` بمقدار 0.10.
- اختلافهما يسقفها عند 0.50، فيظهر الحقل للمراجعة البشرية.
- كل قيمة تحت 0.7 تُعلَّم `review: true` وتصعد لأعلى القائمة.

وطبقة الإثراء لا ترمي خطأ أبداً. عند غياب المفتاح أو نفاد الحصة أو فشل النداء،
تعود النتيجة الحتمية كاملة مع تحذير فقط.

## أهم قرار في التصميم

**المشكلة:** مطابقة المستند بقالبه بدأت بتشابه Jaccard على كل رموز الصفحة الأولى.
القياس على 24 مسحاً حقيقياً لنفس المُصدر أظهر تأرجحاً بين 0.52 و 0.88 لنفس القالب.
ومستند صحيح سقط تحت عتبة 0.50 ورُفض، لأن التشابه يقيس ضجيج المسح لا الهوية.

**القرار:** استبدال التشابه الكلي ببصمة مستند تسأل سؤال الهوية فقط:
هل تحمل الصفحة صياغة ترويسة المُصدر المميزة؟
المقارنة تطوي أخطاء OCR المتكررة (`rn→m`، `0→o`، `1→l`) ثم تقيس مسافة Levenshtein.

**التكلفة والعائد:** كل قالب جديد يحتاج تعريف عبارة ترويسته مرة واحدة عند التدريب.
مقابل ذلك: هوية ثابتة تحت تدهور جودة المسح، وصفر التباس بين قوالب مورّدين مختلفين.

## ماذا في هذا المستودع

الكود ملك جهة العمل، فليس هنا. المستودع يوثّق المعمارية وقرارات البناء.

بنية النظام في الإنتاج:

```
server.js            1,233 سطراً — 34 نقطة نهاية HTTP
lib/                 41 وحدة، 9,273 سطراً — البصمة، OCR، القوالب، الثقة، الميزانية
smoke-*.js           16 حزمة فحص، 232 تحققاً — كلها تعمل دون إنترنت
scripts/             التدريب الجماعي وتصدير المخططات
public/              واجهات الرفع والمراجعة والتدريب
vendor/              بيانات لغتي Tesseract — لا تنزيل وقت التشغيل
```

بوابة التحقق أمر واحد يشغّل سلسلة من 20 خطوة متتابعة: كل حزم الفحص
وإعادة التدريب وتصدير المخططات. أي خطوة تفشل توقف السلسلة كاملة.

وقرار عزل OCR في عملية ابن جاء من عطل حقيقي: صورة JPEG تالفة تُسقط WASM
خارج أي سلسلة وعود. العزل يجعل الانهيار يقتل العملية الابنة فقط، ثم يعاد إحياؤها.

## لماذا بنيته

أعمل مشرف تقنية معلومات، ومطابقة المستندات الممسوحة كانت عملاً يدوياً متكرراً.
المسار الحتمي يرسل 0 ملفات إلى أي خدمة خارجية، والإثراء السحابي اختيار لا التزام.
